## Rolle und Regeln

## Belegter Restblocker

`scripts/build_package.py` nimmt über das rekursive Manifest `data/` alle unbekannten Dateien auf. Der Ausschluss blockiert nur exakt `aura_shared_state.json`. Dadurch können temporäre oder Backup-Dateien mit demselben sensiblen Runtime-State paketiert werden, zum Beispiel:

- `data/aura_shared_state.json.tmp`
- `data/aura_shared_state.tmp`
- `data/aura_shared_state.json.bak`

Diese Dateien können Paper-Trades, Historie und Autobot-State enthalten. Aktuelles ZIP ist sauber; Builder-Vertrag ist trotzdem nicht fail-closed.

## Root Cause / gewünschte Lösung

Nicht weitere einzelne Suffixe erraten. Rekursives `data/`-Packaging ist für einen öffentlichen Release zu breit.

1. Ersetze den rekursiven Manifest-Eintrag `data/` durch eine explizite Allowlist des tatsächlich auszuliefernden statischen Datensatzes:
   - `data/bitget_usdt_futures_universe.json`
2. Behalte zusätzlich einen fail-closed Runtime-State-Familienguard für direkt manipulierte/injizierte Dateilisten. Jede Datei, deren normalisierter Basename zur `aura_shared_state`-Familie gehört, muss abgewiesen werden — inklusive Original, `.json.tmp`, `.tmp`, `.json.bak` und vergleichbarer Suffixvarianten.
3. Bestehende Path-Escape-, Backslash-, Laufwerkspräfix- und Symlink-Guards unverändert erhalten.
4. Keine echten Runtime-State-Inhalte lesen oder ausgeben. Tests nur mit temporären harmlosen Sentinels.
