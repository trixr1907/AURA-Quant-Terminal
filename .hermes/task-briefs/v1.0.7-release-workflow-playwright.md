## Kontext

v1.0.7 wurde nach unabhängiger FREIGABE committed und als annotierter Tag gepusht:

- Commit/Tag-Ziel: `3411674eae7e2b2b521bd23c805413ce792be5c5`

- Noch kein GitHub Release v1.0.7 vorhanden.

## Belegte Root Cause

`.github/workflows/publish-release.yml` führt direkt aus:

- `python3 scripts/release_check.py`
- `python3 scripts/build_package.py`

Auf `ubuntu-latest` fehlt Playwright. `release_check.py` stuft Browser-E2E deshalb korrekt als `CONDITIONAL` ein und beendet mit Exit 2. Log:

- `SKIPPED: playwright not installed in current Python env`
- `VERDICT: CONDITIONAL`

`requirements.txt` pinnt `playwright==1.62.0`.

Ändere ausschließlich:

- `.github/workflows/publish-release.yml`
- passende statische Regressionstests, bevorzugt `tests/test_release_sync.py`

Keine Änderungen an Produktcode, VERSION oder Tag. Tag `v1.0.7` niemals verschieben/löschen/neu erstellen. Keine Commits, Pushes, Releases oder Deployments durch den Subagenten.

- `python3 -m pip install --disable-pip-version-check -r requirements.txt`

Warum `--with-deps`: Browser-Binary allein genügt nicht auf frischem Runner; Systembibliotheken müssen vorhanden sein.
