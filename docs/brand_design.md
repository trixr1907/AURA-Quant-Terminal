# AURA — Confluence Terminal · Brand Identity & Design System

## 🌌 Brand Core

* **Name:** **AURA — Confluence Terminal**
* **Brand Essence:** Das Zusammenspiel aus quantitativer Edge (Multi-Timeframe-Confluence, Regime-Filter, Z-Scores) und menschlicher visueller Kontrolle (TradingView Charts, chirurgische Exekution).
* **Primary Slogan (EN):** *Quantitative Edge. Visual Precision. Pure Execution.*
* **Secondary Slogan (EN):** *Decode the Noise. Execute the Edge.*
* **Claim (DE):** *Mathematischer Vorteil und chirurgische Exekution.*

## 📐 Logo Architecture (12 Figma Types Implementation)

1. **Letterform Mark ("A"):** Geometric vector structure forming the iconic letter "A".
2. **Abstract Facet Geometry:** Shaded carbon facets providing 3D depth and forward momentum.
3. **Combination Mark:** Vector icon coupled with spaced typography (`AURA` + `CONFLUENCE TERMINAL`).
4. **Dynamic Neon Core:** Floating diamond prism glowing in Electric Cyan & Emerald.
